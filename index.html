System Design

How SweepX Cleans Safely

Five specialized modules work together in a strict pipeline to prevent data loss.

1
Unified Multi-Format Scanner
Queries dpkg, pacman, and rpm package managers, iterates Flatpak and Snap runtimes, parses standalone AppImages in ~/Applications, and scans custom desktop files.
Zero Overhead
2
Real-Time Installation Watcher
Uses filesystem change notifications and eBPF probes to capture every file written during make install or manual tar extractions into an installation manifest.
Manifest Log
3
Heuristic Residual Hunter
Checks XDG specification paths (~/.config, ~/.cache, ~/.local/share), user systemd unit files, autostart entries, and resolves broken symlinks.
Pattern Match
4
Multi-Tier Safety Barrier
Blocks deletion targets matching /, /home/$USER, /usr, /etc, /var, or essential system binaries before any deletion begins.
Fail-Safe
5
Atomic Execution & Self-Updater
Atomic file removal with reversible trash backups, alongside background GitHub Releases polling for in-place binary upgrades.
Self-Update

Technical Details

Frequently Explored Questions

Deep dive into technical implementations and safety guarantees.

How does SweepX identify residuals without uninstall hooks?
SweepX combines binary name resolution, desktop file reverse lookup, and standard XDG directory matching (~/.config/<app>, ~/.cache/<app>, ~/.local/share/<app>). It also searches ~/.config/systemd/user/ for associated background services.
Can SweepX accidentally delete system files?
No. The Safety Barrier runs every proposed deletion through an explicit blacklist check. Root folders (/, /usr, /etc, /var), home roots (/home/$USER), and essential libraries are rejected before any disk modification occurs.
How does the 1-Line installer work across different distros?
The install.sh script detects your architecture (x86_64, aarch64), checks GitHub for prebuilt release binaries, sets executable permissions, installs desktop launcher shortcuts and vector SVG icons, and configures your PATH in .bashrc / .zshrc.
